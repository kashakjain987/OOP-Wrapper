PR. 5 - OOP Wrapper


# About Project

This is a simple Employee Management System made using Python.
It demonstrates basic Object-Oriented Programming (OOP) concepts.

# Features

Create Employee
Create Manager
Create Developer
Display employee details
Use OOP concepts



# OOP Concepts Used

Encapsulation – Data is kept private.
Inheritance – Manager and Developer inherit from Employee.
Method Overriding – display() is changed in child classes.
Constructor – Used to create objects.
super() – Used to call the parent class constructor.
Getter and Setter – Used to access and update data.
issubclass() – Checks the relationship between classes.


# Technologies

Python
VS Code
